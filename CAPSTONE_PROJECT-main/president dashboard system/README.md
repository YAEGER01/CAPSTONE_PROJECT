# President Dashboard System

This folder is reserved for the president dashboard design and supporting documentation.

The actual Django dashboard implementation is available in the project at:
- `website/views.py`
- `website/urls.py`
- `templates/website/dashboard.html`
- `static/css/dashboard.css`

Copies of the dashboard design are also stored here for reference:
- `templates/website/dashboard.html`
- `static/css/dashboard.css`

Login is handled by `website/views.py` and the dashboard is protected with Django authentication.
